Методология
Посты собраны из открытых провоенных (Z) Telegram-каналов за ±3 дня вокруг каждого события. Каждый пост проанализирован LLM (Gemini Flash) по шкалам тональности (−5..+5) и эмоциональной интенсивности (0..5), с классификацией настроения по 10 категориям. Учитываются только посты с релевантностью ≥ 0.5 к конкретному событию. Примеры постов отбираются с порогом ≥ 0.7. Анализ продолжается — данные обновляются по мере обработки новых событий.
